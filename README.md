# T Waterter

A touch-friendly Caribbean fishing game for desktop and mobile browsers. It uses a custom JavaScript renderer with a Canvas fallback and does not use Three.js.

## Play

After GitHub Pages finishes its first deployment, open the Pages URL from the repository's **Settings → Pages** page on your phone. In the phone browser, choose **Add to Home Screen** to keep a shortcut.

Every push to `main` automatically updates the game. No Node.js server is needed for GitHub Pages.

- Visit Elias to sell catches and upgrade equipment.
- Tap **PALM POINT** to change fishing location.
